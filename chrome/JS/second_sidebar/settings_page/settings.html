Second Sidebar

Web panels next to your tabs. Changes apply right away, in every window. Each panel has its own settings too: right-click its button and choose Edit web panel.

Settings imported. Restart the browser to apply them; until then, changes to the sidebar and web panels aren't saved.

Keyboard shortcuts

Click a box and press the keys; Backspace clears it. Shortcuts follow the keys' places on the keyboard, so they keep working when you switch layouts. Each web panel can have one too: right-click its button and choose Edit web panel.

Backup

Save your settings and web panels to a file, to restore them later or in another profile. You choose what goes in, and what to restore from it.
